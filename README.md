# Sagar Kale — Portfolio

My personal developer portfolio, showcasing my skills, experience, and real projects as a Java Full Stack Developer.

🔗 **Live Site:** [sagarkale18.github.io/Portfolio](https://sagarkale18.github.io/Portfolio/)

## Sections
- **Hero** — animated intro with a typing effect cycling through my roles
- **About** — background, education, and quick stats
- **Skills** — animated progress bars for my core tech stack
- **Experience** — internship timeline (Qweez Technology, MotionCut)
- **Projects** — 6 real, live GitHub projects with direct code links
- **Contact** — direct email, phone, LinkedIn, GitHub, and a message form

## Tech Stack
- HTML5, CSS3, JavaScript (Vanilla)
- Google Fonts (Outfit, Fira Code)
- Custom CSS animations (blobs, scroll-reveal, 3D card tilt, typing effect)

## Getting Started
Clone and open locally:
```bash
git clone https://github.com/SagarKale18/Portfolio.git
cd Portfolio
```
Just open `index.html` in your browser — no build step required.
